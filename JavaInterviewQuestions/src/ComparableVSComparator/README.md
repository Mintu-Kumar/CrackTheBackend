
1. Problem Statement -  What is the difference between comparable and comparator.


Comparable

    1. Used for Natural order sorting
    2. Comparable has compareTo() method
    3. sorting logic within the class
    4. Collection.sort(obj);


Comparator

    1. Used for Custom order sorting
    2. Comparator has compare() method
    3. Sorting logic outside the class
    4. Collections.sort(obj, sorting class obj);
