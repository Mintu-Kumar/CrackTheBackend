

==  .equals()

== - to compare the reference

String class
.equals() -  to compare the content of object



Custom class
Name  -  Student

Case1  -  Student class has not overridden .equals() method of object class
In that case -  if we compare two object of student class using .equals() then it will compare the reference

Case 2 - if Student class has overridden .equal() method of object class.
in that case -  if we compare the two object of student class using.equals() then it will compare the content
